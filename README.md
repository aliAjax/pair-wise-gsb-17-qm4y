# 泥浆循环与漏失处置台

钻井现场泥浆循环量登记与漏失处置面板。按班登记罐余量、注入量、回流量与观测时刻，自动核算前后班实际消耗；消耗异常时立案锁定孔位，封堵信息与回流复核齐备并写明恢复结果后才能解锁恢复钻进。

## 技术栈

React 19 + Vite + TypeScript + CSS（数据存于浏览器 localStorage，无需后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务规则

- **班次登记**：孔号、当前深度、班次（白/夜班）、罐余量、注入量、回流量、观测时刻。
- **实际消耗**（同孔按观测时刻排序，逐班推算）：
  `消耗 = 注入量 − 回流量 +（上班罐余量 − 本班罐余量）`；每孔首班为基准班，不参与对比。
- **异常立案**：本班消耗较前班高出两成（>20%）时，自动把孔号、深度、差值列入“待处理”并锁定该孔；锁定期间继续登记的超限班次记入升级留痕。
- **锁定限制**：孔位锁定期间禁止新增该孔的本班记录。
- **解锁四条件**（缺一不可，按钮保持禁用）：
  1. 已登记封堵材料；
  2. 已指定责任人；
  3. 两次回流观测稳定（绝对波动 ≤0.5m³ 或相对 ≤5%）且间隔不少于 1 小时；
  4. 已写明恢复结果。
- 解锁后事件归档到“处置历史”，可随时展开复核。
- 循环记录与处置历史使用**两个独立的 localStorage 键**分开保存，重开页面自动恢复，接着处理未结事件。
- “载入演示数据”可快速演示完整流程（ZK-18 处于锁定待处理状态）。
