# 泥浆循环与漏失处置台

现场泥浆循环登记与漏失处置管控面板：按班次记录罐余量、注入量、回流量和观测时刻，自动核算实际消耗，消耗异常时锁定钻孔、跟踪处置直到满足解锁条件。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5103

## 业务规则

- **班次登记**：孔号、孔深、班次（白班/夜班）、观测时刻、罐余量、注入量、回流量。
- **实际消耗**：实际消耗 = 注入量 − 回流量，自动与同一孔号前一班记录对比。
- **两成预警**：本班实际消耗高出前班 20% 时，自动生成漏失处置单，列出孔号、孔深与差值，进入「待处理」，顶部横幅锁定该孔。
- **三道解锁闸**（缺一不可，未登记封堵材料和责任人不能恢复钻进）：
  1. 登记封堵材料（含用量）与责任人、处置说明；
  2. 处置后两次回流稳定（回流率 ≥ 95%）且观测间隔不少于 60 分钟；
  3. 写明恢复钻进结果（不少于 5 字），随后解锁。
- **数据分离**：循环记录（`mud-console:circulation:v1`）与处置历史（`mud-console:tickets:v1`）分别保存在浏览器 localStorage，刷新或重开面板后可接着处理；已解锁处置单可在「处置历史」中查看。
